# Firebase-database-connection
1. Add application code to lib/main.dart file
2. Add dependencies like:
3. flutter pub get
4. flutter pub add firebase_core
5. flutter pub add firebase_database
6. flutter pub add firebase_auth
7. Copy the Firebase Realtime Database URL from your Firebase project by visiting the Firebase Console and opening the project connected to your Flutter application.
8. flutter build apk --release.
