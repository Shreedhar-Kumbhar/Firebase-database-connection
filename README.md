# Flutter Firebase Student Management App

A simple Flutter application integrated with **Firebase Realtime Database** to manage student records.

### Features
- Add student records.
- View student details.
- Update student information.
- Delete student records.

### Technologies Used
- Flutter
- Dart
- Firebase Realtime Database

### Installation Commands

```bash
flutter pub get
flutter run
```

### Firebase Configuration

```bash
flutter pub add firebase_core
flutter pub add firebase_database
flutterfire configure
```

### Developer Tools
- Visual Studio Code
- Android Emulator
- Firebase Console
